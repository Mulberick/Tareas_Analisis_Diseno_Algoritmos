## Temas Cubiertos

Este semestre se abordaron los principales temas de diseño de algoritmos como son:

* **Ordenamiento:** algoritmos cuadráticos clásicos vs. Merge Sort (divide y vencerás).
* **Búsqueda de patrones:** fuerza bruta vs. hashing (Rabin-Karp).
* **Algoritmos voraces (greedy):** Kruskal, Prim, Dijkstra.
* **Recorridos en grafos:** BFS, DFS, Orden Topológico.
* **Programación dinámica:** Fibonacci, Laberinto del Tesoro, LCSS, Knapsack 0/1.
* **Codificación óptima:** Huffman (proyecto final).

Cada repositorio individual incluye metodología experimental, entorno de pruebas, descripción y complejidad de los algoritmos implementados, tabla de resultados y gráficas comparativas de tiempo de ejecución y número de operaciones.
